 JMeter Performance Testing

## 📚 Topics Covered

### 1. Java & JMeter Setup
- Java JDK 27 installation
- JAVA_HOME configuration
- Apache JMeter installation and setup

### 2. JMeter Scripting
- Creating JMeter test scripts
- Recording browser actions using BlazeMeter
- Configuring browser proxy
- Using JMeter Test Script Recorder
- Working with `.jmx` test plans

### 3. Thread Groups
- Basic Thread Group
- Advanced Thread Group
- Concurrency Thread Group
- Ultimate Thread Group
- Understanding virtual users, ramp-up and duration

### 4. Listeners & Result Analysis
- View Results Tree
- Summary Report
- Aggregate Report
- Understanding performance metrics:
  - Average Response Time
  - Median
  - Throughput
  - P90
  - P95
  - Error %
